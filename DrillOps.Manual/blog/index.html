DrillOps Desktop 0.11.0-beta

21 октября 2026 г.

Наземные рейсы, инцидент на оборудовании, пакетные операции обслуживания и порядок статусов в аналитике.

⚠️ Обновляйте Desktop и API вместе до 0.11.0-beta.
Contract v11 — вход на старый сервер будет заблокирован.

Новое​

Рейсы​

  • Рейсы делятся на подземные и наземные. У типа оборудования задаётся размещение: наземное или подземное; уже заведённые типы остаются подземными
  • У наземного рейса состав без пометки КНБК, даты начала и конца работы; проходка и параметры раствора не заполняются
  • Инцидент отмечается на выбранном оборудовании состава. Если раньше он стоял на весь рейс, отметка переносится на каждое оборудование этого состава
  • В списке рейсов заказчика можно выбрать несколько значений и искать по названию

Обслуживание​

  • Извлечение и установку можно провести сразу по нескольким компонентам
  • В установке несколько слотов: строку можно добавить или убрать
  • Статус «На расследовании» — оборудование остаётся в колонке обслуживания

Аналитика​

  • Порядок типов в сводке по статусам можно переставить и сохранить на этом экране или записать общим для всех пользователей
  • Инциденты фильтруются по текущему статусу оборудования

Отправки​

  • Вкладка открытой отправки называется «Отправка №…»
  • Файлы отправок одной группы общие: при объединении собираются вместе, при удалении участника остаются у остальных

Исправления​

Отправки​

  • Даты начала и конца отправки больше не сбрасываются при сохранении
  • При фактической отправке запланированной записи с датой начала в будущем эта дата становится сегодняшней

Заказ-наряды​

  • Закрытие последнего открытого наряда возвращает оборудование в «Готово», если оно не в поле и не списано. Колонка на главной обновляется сразу

DrillOps Desktop 0.10.5-beta

20 октября 2026 г.

Привязка установки и извлечения к заказ-наряду компонента.

✅ Contract v10 — обновление не блокирует вход.
Совместимо с API 0.10.4-beta

Новое​

Заказ-наряд​

  • Установку и извлечение можно привязать к существующему заказ-наряду того же компонента, сменить привязку или снять её. Серийный номер открывает этот наряд
  • В окне выбора наряд ищется по номеру и дате
  • Привязка только ведёт на наряд: он не создаётся заново и не удаляется. Отмена операции его не трогает

Исправления​

Обслуживание​

  • Список не затирается более ранней загрузкой, если следом пришло свежее обновление

DrillOps Desktop 0.10.6-beta

20 октября 2026 г.

Детализация аналитики, меню компонентов и название хранилища.

✅ Contract v10 — обновление API не требуется.
Совместимо с API 0.10.5-beta

Новое​

Аналитика​

  • В ячейках сводки по статусам — подсказка со списком оборудования. Можно скопировать текст и открыть сборку, отгрузку, заказ-наряд, полевые данные или сводку
  • Инциденты и отклонения раскрываются по типу и серийному номеру до отдельных записей с деталями

Компоненты​

  • В контекстном меню пункт «Открыть последний ЗН». Пункт, который сам создавал обслуживание и наряд, убран — отправка в обслуживание остаётся отдельной командой

Файловое хранилище​

  • Вкладка «Документация» переименована в «Файловое хранилище»

Исправления​

Сборки​

  • После создания сборки список сборок обновляется сразу, без перезагрузки экрана

DrillOps Desktop 0.10.4-beta

16 октября 2026 г.

Операции в старом заказ-наряде, состав на дату завершения, наименование в отгрузках.

✅ Contract v10 — обновление не блокирует вход.
Совместимо с API 0.10.3-beta

Новое​

Отгрузки​

  • В списке и карточке рядом с серийным номером видны наименование и PN. По ним работает поиск

Исправления​

Заказ-наряд​

  • Установка и извлечение в старом заказ-наряде остаются в журнале и не меняют текущую сборку, статус и место инструмента
  • Завершённый старый наряд показывает состав на дату завершения. Незавершённый старый наряд показывает текущую сборку вместе с операциями этого наряда
  • В списке на установку по дате старого наряда попадают детали, свободные в этот день, в том числе занятые сейчас. Уже стоящие в другой сборке и списанные к этой дате в список не попадают
  • Дата операции не может быть позже даты завершения заказ-наряда
  • Снять завершение нельзя, если для этого инструмента уже есть более поздний заказ-наряд
  • Извлечение находит деталь в слоте, даже если ссылка на строку состава устарела

Обслуживание​

  • Удаление записи обслуживания уносит связанный заказ-наряд, операции и вложения. Восстановление возвращает их вместе и сохраняет связь операции с её отменой
  • Операция, удалённая раньше этой записи, из корзины не возвращается

Рейсы​

  • Список отправок и окна дат обновляются сразу после изменения отгрузки, без перезагрузки вкладки

DrillOps Desktop 0.10.3-beta

14 октября 2026 г.

Завершение старого заказ-наряда и связь установки с нарядом.

✅ Contract v10 — обновление не блокирует вход.
Совместимо с API 0.10.2-beta

Исправления​

Заказ-наряд​

  • Завершение старого заказ-наряда не выводит инструмент из поля и не снимает его с более позднего обслуживания
  • В «готово» переводит только завершение текущего обслуживания
  • Серийный номер в операции установки открывает ближайший более ранний заказ-наряд этого номера
  • Более поздний наряд того же номера забирает связь с даты своего начала: установка до этой даты открывает прежний наряд

Обслуживание​

  • Номер заказ-наряда в списке можно выделить. Открыть наряд — кнопкой в строке

DrillOps Desktop 0.10.2-beta

13 октября 2026 г.

Обслуживание задним числом, связь заказ-наряда у извлечения, рейсы.

✅ Contract v10 — обновление не блокирует вход.
Совместимо с API 0.10.1-beta

Новое​

Обслуживание​

  • Администратор записывает обслуживание задним числом: Shift+клик по «Отправить на обслуживание» на главной или по «Добавить запись» в списке обслуживания
  • Создаётся запись обслуживания и заказ-наряд, сборка остаётся на месте. Можно сразу отметить завершение и указать дату окончания — не раньше начала и не позже сегодня
  • После записи открывается заказ-наряд. «Открыть обслуживание» у сборки открывает заказ-наряд последней записи, если он уже есть

Исправления​

Заказ-наряд​

  • Серийный номер в операции извлечения открывает заказ-наряд, созданный этой операцией
  • У старых извлечений, где заказ-наряд обслуживания отличался от наряда операции, связь восстанавливается
  • Серийный номер в операции установки заказ-наряд не открывает

Рейсы​

  • При возврате из карточки список остаётся на той же видимой строке
  • «Предыдущий рейс» и «Следующий рейс» доступны на карточке просмотра и недоступны, пока рейс правят или сохраняют
  • После удаления рейса таблица не прокручивается к его раскрытым деталям

DrillOps Desktop 0.10.0-beta

12 октября 2026 г.

Рейсы, плановые отправки, списание компонента и лента времени.

⚠️ Обновляйте Desktop и API вместе до 0.10.0-beta.
Contract v10 — вход на старый сервер будет заблокирован.

Новое​

Отправки​

  • Мастер отправки: сборки, место и дата; отправить сразу или запланировать
  • Запланированная отправка не занимает сборку в поле, пока её не отправят
  • В одну отправку можно добавить дополнительные сборки помимо основной
  • Запланированную отправку можно отменить: запись остаётся в списке со статусом «Отменено» и не занимает сборку
  • Запланированные отправки остаются в одной группе, только если совпадают заказчик, куст и скважина; уже отправленные держатся вместе по дате и месту
  • В списке виден номер отправки из шести цифр

Рейсы​

  • Отдельный раздел «Рейсы»: состав КНБК, фильтры, номер рейса и история правок
  • Рейс — самостоятельная запись, а не отчёт внутри документа полевых данных
  • Рейс привязывается к отправке; даты спуска и подъёма должны целиком лежать в окне отправки каждого инструмента

Обслуживание​

  • Компонент сборки можно списать отдельно: он снимается со сборки, материал помечается списанным
  • В заказ-наряде компонента видны последнее извлечение и установка, со ссылкой на заказ-наряд, где это сделано

Аналитика​

  • Лента времени: нахождение в поле, рейсы и обслуживание; из полосы открываются отправка, рейс или обслуживание

Текстовые шаблоны​

  • У шаблона сразу причина и описание; он действует на выбранные типы операций

Исправления​

Обслуживание​

  • Полевые данные компонента берутся из отправки, где он стоял на инструменте
  • Более поздняя отправка и запланированная, если инструмент не уезжал, в обслуживание не подставляются

Списки​

  • При переключении вкладок список не сбрасывается в начало

DrillOps Desktop 0.10.1-beta

12 октября 2026 г.

Отправка задним числом, состав на дату отправки, графики и заказ-наряд.

✅ Contract v10 — обновление не блокирует вход.
Совместимо с API 0.10.0-beta

Новое​

Отправки​

  • Администратор записывает отправку задним числом: Shift+клик по «Отправить в поле» или по «Добавить» в списке отправок
  • Создаётся запись отправки, сборка остаётся на месте. Можно сразу отметить возвращение и указать его дату — не раньше отправки и не позже сегодня

Состав отправки​

  • Дерево на карточке строится на дату отправки по журналу установки, извлечения и списания. Смена даты перестраивает состав

Исправления​

Аналитика​

  • Обновление данных дожидается конца загрузки и освобождает старые рисунки графиков после нового кадра
  • Закрытие вкладки останавливает перерисовку графиков

Заказ-наряд​

  • Операцию с датой вне уже сохранённого окна можно записать: окно сначала расширяется под новые даты, затем сохраняются даты из карточки
  • Мастера операции, ввода в эксплуатацию и отправки оставляют исходное окно доступным. Повторный вызов показывает уже открытый мастер

Рейсы​

  • Список остаётся на той же прокрутке при возврате из карточки рейса
  • Пункты контекстного меню снова доступны, когда действие можно выполнить
  • Состав КНБК меняется, пока рейс открыт на правку

Интерфейс​

  • Закрытые экраны освобождаются вместе со строками локализации
  • В текстовых полях хранится до ста шагов отмены
