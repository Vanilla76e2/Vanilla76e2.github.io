Продвинутое использование

Обычные экраны описаны в своих главах. Здесь — жесты, которые не подписаны крупно на кнопках: контекстное меню, горячие клавиши, перетаскивание.

Контекстное меню (ПКМ)​

Правый щелчок по строке, карточке или узлу дерева открывает действия «отсюда», без похода в другое меню.

Заказ-наряд → дерево структуры​

ПКМ по узлу в панели Структура:

  • Создать операцию — открывает мастер уже с выбранным компонентом или пустым слотом. Для занятого узла мастер готов к Разборке / Утилизации; для пустого слота — к Сборке.
  • Открыть компонент / Открыть тип / Открыть сборку — карточка в справочнике.
  • Последняя отправка, Последний заказ-наряд, полевые данные, Открыть сводку.

Корневой узел сборки операцию из меню не создаёт — выберите вложенный компонент или пустой слот.

Скриншот (добавить): ПКМ по компоненту в дереве заказ-наряда, пункт «Создать операцию».

Главная​

ПКМ по карточке сборки: открыть сборку, последнюю отправку, наряд, полевые данные, сводку; Отправить в поле / на обслуживание; Полевые данные и Открыть обслуживание.

ПКМ по узлу дерева справа: Открыть компонент, Открыть тип, Открыть сводку.

С Ctrl или Shift можно выделить несколько карточек и отправить их вместе — то же меню работает для пакета.

Отфильтровать по SN подставляет серийный номер строки в поиск списка — удобно, когда нужно оставить только эту единицу.

Жёлтое предупреждение в тексте (Ctrl+W)​

В описании операции (мастер Новая операция, поле описания в наряде, заготовка типа Описание, диалог утилизации) можно отметить фрагмент как предупреждение.

  1. Выделите текст.
  2. Нажмите Ctrl+W.
  3. Фрагмент подсветится жёлтым. Повтор по тому же фрагменту снимает отметку.

В списках и в сводке такая разметка тоже жёлтая. Подсказка «?» рядом с полем описания в мастере повторяет это же правило.

Скриншот (добавить): описание операции с жёлтым фрагментом после Ctrl+W.

Вкладки и окна​

  • Повторный щелчок по пункту меню не плодит вкладку — переключает на уже открытую. Чтобы открыть вторую такую же, сначала оторвите текущую: потяните ярлык вверх или вниз.
  • Оторванная вкладка живёт в отдельном окне (тот же Alt+← / Alt+→).
  • Подписи и значения в карточках можно копировать через ПКМ — не нужно перепечатывать серийный номер.

Перетаскивание файлов​

Вложения в заказ-наряде и отправке, а также файлы в Документации можно не только выбрать кнопкой Добавить, но и перетащить с рабочего стола. В документации двойной щелчок открывает файл во внешней программе. На экране полевых данных вложения рейса только смотрят.

Что ещё легко пропустить​

  • На Главной из дерева структуры открывается сводка выбранного узла, не только всей сборки.
  • Неполную сборку всё равно можно отправить или закрыть наряд — программа запросит подтверждение.
  • Заказ-наряд с Главной открывается, когда у сборки уже есть запись обслуживания. Полевые данные для этого закрывать не нужно: рейсы правят на вкладке Рейсы.
  • Если карточку одновременно сохранил другой пользователь, баннер Принять обновление / Оставить мои изменения — это конфликт правок, а не обновление программы. Подробнее в FAQ.
