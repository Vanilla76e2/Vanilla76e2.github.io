# Главное окно

![Главное окно](./img/Main-Window.png)

## Навигация

Слева — панель навигации (на скриншоте). Сверху видны **имя пользователя** и **роль**. Нажмите пункт, чтобы открыть вкладку.

Пункты меню ведут на главы руководства: [Главная](../Рабочий%20цикл/Главная.md), [Аналитика](../Отчёты/Аналитика.md), [Компоненты](../Справочники/Компоненты.md), [Сборки](../Справочники/Сборки.md), [Отправки](../Рабочий%20цикл/Отправки.md), [Рейсы](../Рабочий%20цикл/Рейсы.md), [Обслуживание](../Рабочий%20цикл/Обслуживание.md), [Локации](../Справочники/Локации.md), [Заказчики](../Справочники/Заказчики.md), [Заготовки описаний](../Сервис/Заготовки%20описаний.md), [Документация](../Сервис/Документация.md).

Когда доступна новая версия, сверху списка появляется пункт **Обновление**. После первого входа на новую версию может открыться вкладка **Что нового** с патчноутом.

[Полевые данные](../Рабочий%20цикл/Полевые%20данные.md), [заказ-наряд](../Рабочий%20цикл/Заказ-наряд.md) и [сводка](../Отчёты/Сводка.md) в меню нет — они открываются из других экранов.

Внизу панели: **Свернуть / развернуть меню** (`Ctrl+B`) и **Выйти** (`Ctrl+Q`).

> Некоторые пункты скрыты, в соответствии с настроенными правами.

> Если вкладка уже открыта, повторный щелчок в меню переключит на неё, а не создаст вторую. Чтобы открыть ещё одну такую же, сначала вытащите текущую вкладку в отдельное окно.

## Вкладки

Панель вкладок — сверху окна. Кнопки **На предыдущую вкладку** и **На следующую вкладку** ходят по истории посещений, а не по порядку ярлыков (`Alt+←` / `Alt+→`).

> Вкладку можно оторвать в отдельное окно: зажмите её левой кнопкой и потяните вверх или вниз. Остальные жесты и клавиши собраны в [продвинутом использовании](../Продвинутое%20использование.md).

## Шапка

Справа в шапке:

- Переключатель **языка** (русский / английский);
- **Обновить данные (`F5`)** — заново загружает кэш с сервера;
- Переключатель **темы** (светлая / тёмная);
- Кнопка **Руководство** — открывает этот сайт в браузере.

## Элементы экрана

Полный перечень панелей, кнопок, ПКМ и клавиш. Как пользоваться по задаче — в тексте выше. Общие жесты окна — в [продвинутом использовании](../Продвинутое%20использование.md).
