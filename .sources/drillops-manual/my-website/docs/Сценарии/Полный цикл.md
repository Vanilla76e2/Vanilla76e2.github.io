# Полный цикл

Сквозной маршрут оборудования в DrillOps — от создания до повторной отправки. Каждый этап подробно описан в отдельном сценарии; здесь — общая картина.

```
Справочники → Главная «Готовы» → Отправка → Рейсы → На обслуживании → Готовы → …
```

## Этапы

### 1. Подготовка справочников

Заведите [заказчиков](../Справочники/Заказчики.md), [локации](../Справочники/Локации.md) и [компоненты](../Справочники/Компоненты.md). Создайте [шаблон](../Справочники/Шаблоны.md) и [сборку](../Справочники/Сборки.md). Пустую сборку удобно укомплектовать **мастером создания**: он закроет обслуживание и заказ-наряд первичной комплектации. Уже заведённые компоненты ставят операцией **Сборка** в заказ-наряде.

![Как завести сборку](./Как%20завести%20сборку.md)

### 2. Отправка в поле

С [Главной](../Рабочий%20цикл/Главная.md) откройте мастер **Отправка**. **Отправить сейчас** переносит сборку в **В поле**. **Запланировать** оставляет её на месте до отдельной отправки. В [Отправках](../Рабочий%20цикл/Отправки.md) фиксируется снимок состава.

![Как отправить в поле](./Как%20отправить%20в%20поле.md)

### 3. Рейсы

На вкладке [Рейсы](../Рабочий%20цикл/Рейсы.md) заведите спуски: состав, даты, часы, метры, инцидент. Рейс сохраняется, если его даты лежат внутри отправки каждого инструмента. [Полевые данные](../Рабочий%20цикл/Полевые%20данные.md) отправки показывают эти рейсы и сами ничего не редактируют.

![Как завести рейс](./Как%20заполнить%20полевые%20данные.md)

### 4. Обслуживание

Когда инструмент вернулся, отправьте его **на обслуживание** с Главной — у отправки появится дата возвращения. Откройте [заказ-наряд](../Рабочий%20цикл/Заказ-наряд.md), добавьте [операции](../Рабочий%20цикл/Операции.md), прикрепите файлы. Завершите обслуживание — сборка вернётся в **Готовы**.

![Как провести обслуживание](./Как%20провести%20обслуживание.md)

### 5. Повторная отправка

Цикл замкнулся: сборка снова в **Готовы** и может ехать к заказчику. Хронология одной сборки — в [Сводке](../Отчёты/Сводка.md), цифры по парку — в [Аналитике](../Отчёты/Аналитика.md).
