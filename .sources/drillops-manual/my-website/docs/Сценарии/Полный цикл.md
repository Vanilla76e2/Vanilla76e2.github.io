# Полный цикл

Сквозной маршрут оборудования в DrillOps — от создания до повторной отправки. Каждый этап подробно описан в отдельном сценарии; здесь — общая картина.

```
Справочники → Главная «Готовы» → В поле → На обслуживании → Готовы → …
```

## Этапы

### 1. Подготовка справочников

Заведите [заказчиков](../Справочники/Заказчики.md), [локации](../Справочники/Локации.md) и [компоненты](../Справочники/Компоненты.md). Создайте [шаблон](../Справочники/Шаблоны.md) и [сборку](../Справочники/Сборки.md), укомплектуйте её.

Подробнее: [Как завести сборку](./Как%20завести%20сборку.md)

### 2. Отправка в поле

С [Главной](../Рабочий%20цикл/Главная.md) отправьте сборку заказчику. Она переместится в столбец **В поле**, а в [Отправках](../Рабочий%20цикл/Отправки.md) зафиксируется снимок.

Подробнее: [Как отправить в поле](./Как%20отправить%20в%20поле.md)

### 3. Возврат и полевые данные

Когда инструмент вернулся, отправьте его **на обслуживание** с Главной. Создайте [полевые данные](../Рабочий%20цикл/Полевые%20данные.md): внесите отчёты о рейсах, параметры бурения, вибрации, отметьте инцидент при необходимости. Завершите ПД.

Подробнее: [Как заполнить полевые данные](./Как%20заполнить%20полевые%20данные.md)

### 4. Обслуживание

Откройте [заказ-наряд](../Рабочий%20цикл/Заказ-наряд.md), добавьте [операции](../Рабочий%20цикл/Операции.md) (инспекция, ремонт, замена и т.д.), прикрепите файлы. Завершите обслуживание — сборка вернётся в **Готовы**.

Подробнее: [Как провести обслуживание](./Как%20провести%20обслуживание.md)

### 5. Повторная отправка

Цикл замкнулся: сборка снова в **Готовы** и может ехать к заказчику. Вся хронология доступна в [Сводке](../Отчёты/Сводка.md), статистика по парку — в [Аналитике](../Отчёты/Аналитика.md).

## Схема

| Этап            | Где происходит                                                                                  | Результат                    |
| --------------- | ----------------------------------------------------------------------------------------------- | ---------------------------- |
| Создание сборки | [Справочники](../Справочники/Компоненты.md)                                                     | Сборка в **Готовы**          |
| Отправка        | [Главная](../Рабочий%20цикл/Главная.md) → [Отправки](../Рабочий%20цикл/Отправки.md)             | Сборка в **В поле**          |
| Возврат         | [Главная](../Рабочий%20цикл/Главная.md)                                                         | Сборка в **На обслуживании** |
| Полевые данные  | [Обслуживание](../Рабочий%20цикл/Обслуживание.md) → [ПД](../Рабочий%20цикл/Полевые%20данные.md) | ПД закрыты                   |
| Заказ-наряд     | [Обслуживание](../Рабочий%20цикл/Обслуживание.md) → [ЗН](../Рабочий%20цикл/Заказ-наряд.md)      | Обслуживание завершено       |
| Снова готова    | [Главная](../Рабочий%20цикл/Главная.md)                                                         | Сборка в **Готовы**          |
