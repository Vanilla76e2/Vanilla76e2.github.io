# Продвинутое использование

Обычные экраны описаны в своих главах. Здесь — жесты, которые не подписаны крупно на кнопках: контекстное меню, горячие клавиши, перетаскивание.

## Контекстное меню (ПКМ)

Правый щелчок по строке, карточке или узлу дерева открывает действия «отсюда», без похода в другое меню.

### Заказ-наряд → дерево структуры

ПКМ по узлу в панели **Структура**:

- **Создать операцию** — открывает мастер уже с выбранным компонентом или пустым слотом. Для занятого узла мастер готов к **Разборке** / **Утилизации**; для пустого слота — к **Сборке**.
- **Открыть компонент** / **Открыть тип** / **Открыть сборку** — карточка в справочнике.
- **Последняя отправка**, **Последний заказ-наряд**, полевые данные, **Открыть сводку**.

Корневой узел сборки операцию из меню не создаёт — выберите вложенный компонент или пустой слот.

> **Скриншот (добавить):** ПКМ по компоненту в дереве заказ-наряда, пункт «Создать операцию».

### Главная

ПКМ по карточке сборки: открыть сборку, последнюю отправку, наряд, полевые данные, сводку; **Отправить в поле** / **на обслуживание**; **Полевые данные** и **Открыть обслуживание**.

ПКМ по узлу дерева справа: **Открыть компонент**, **Открыть тип**, **Открыть сводку**.

С **Ctrl** или **Shift** можно выделить несколько карточек и отправить их вместе — то же меню работает для пакета.

### Списки

| Где | Что делает ПКМ |
| --- | --- |
| [Сборки](./Справочники/Сборки.md) | Последняя отправка, наряд, полевые данные, сводка, **Открыть шаблон** |
| Дерево сборки / шаблона | Компонент, тип, сводка; **Извлечь** / **Удалить слот** / **Изменить** |
| [Обслуживание](./Рабочий%20цикл/Обслуживание.md) | Сводка, отправка, полевые данные, открыть обслуживание, **Отфильтровать по SN** |
| [Отправки](./Рабочий%20цикл/Отправки.md) | Сборка, наряд, полевые данные, сводка, **Отправить на обслуживание**, **Отфильтровать по SN**, **Создать рейс** |
| [Рейсы](./Рабочий%20цикл/Рейсы.md) | Открыть, удалить, отправка, полевые данные, заказ-наряд |
| [Компоненты](./Справочники/Компоненты.md) | **Открыть сводку**; **Переместить** вид/тип/вариант/компонент в другую ветку (если экземпляр не стоит в сборке) |
| [Сводка](./Отчёты/Сводка.md) | **Скрыть** сегмент шкалы, **Открыть** документ, **К полевым данным** |
| Снимок в [отправке](./Рабочий%20цикл/Отправки.md) | Переход к связанным документам по узлу |

**Отфильтровать по SN** подставляет серийный номер строки в поиск списка — удобно, когда нужно оставить только эту единицу.

## Жёлтое предупреждение в тексте (`Ctrl+W`)

В описании операции (мастер **Новая операция**, поле описания в наряде, заготовка типа **Описание**, диалог утилизации) можно отметить фрагмент как предупреждение.

1. Выделите текст.
2. Нажмите **Ctrl+W**.
3. Фрагмент подсветится жёлтым. Повтор по тому же фрагменту снимает отметку.

В списках и в [сводке](./Отчёты/Сводка.md) такая разметка тоже жёлтая. Подсказка «?» рядом с полем описания в мастере повторяет это же правило.

> **Скриншот (добавить):** описание операции с жёлтым фрагментом после Ctrl+W.

## Горячие клавиши

| Клавиши | Где | Действие |
| --- | --- | --- |
| `Ctrl+B` | Везде | Свернуть / развернуть боковое меню |
| `Ctrl+Q` | Везде | Выйти |
| `F5` | Везде | [Обновить данные](./Начало%20работы/Главное%20окно.md) с сервера |
| `Alt+←` / `Alt+→` | Вкладки | Назад / вперёд по истории вкладок |
| `Ctrl+W` | Описание операции | Жёлтое предупреждение |
| `Ctrl+N` | Компоненты, заказчики, локации, заготовки, обслуживание | Добавить запись |
| `Enter` | [Компоненты](./Справочники/Компоненты.md) | Редактировать / сохранить |
| `Esc` | Компоненты | Отмена правки |
| `Del` | Компоненты | Удалить выбранное |
| `↑` `↓` `→` `←` | Компоненты | Ходить по дереву (→ открыть, ← назад) |
| `Ctrl+C` `X` `V` | [Документация](./Сервис/Документация.md) | Копировать / вырезать / вставить файлы |
| `F2` | Документация | Переименовать |
| `Delete` | Документация | Удалить |
| `Shift+F1` | Любое окно | Открыть папку журнала программы (для разбора сбоев) |

На вкладке [Компоненты](./Справочники/Компоненты.md) полный список клавиш всплывает по значку **?**.

## Вкладки и окна

- Повторный щелчок по пункту меню не плодит вкладку — переключает на уже открытую. Чтобы открыть вторую такую же, сначала **оторвите** текущую: потяните ярлык вверх или вниз.
- Оторванная вкладка живёт в отдельном окне (тот же `Alt+←` / `Alt+→`).
- Подписи и значения в карточках можно **копировать** через ПКМ — не нужно перепечатывать серийный номер.

## Перетаскивание файлов

Вложения в [заказ-наряде](./Рабочий%20цикл/Заказ-наряд.md) и [отправке](./Рабочий%20цикл/Отправки.md), а также файлы в [Документации](./Сервис/Документация.md) можно не только выбрать кнопкой **Добавить**, но и **перетащить** с рабочего стола. В документации двойной щелчок открывает файл во внешней программе. На экране [полевых данных](./Рабочий%20цикл/Полевые%20данные.md) вложения рейса только смотрят.

## Что ещё легко пропустить

- На [Главной](./Рабочий%20цикл/Главная.md) из дерева структуры открывается сводка выбранного узла, не только всей сборки.
- Неполную сборку всё равно можно отправить или закрыть наряд — программа запросит подтверждение.
- Заказ-наряд с Главной открывается, когда у сборки уже есть запись обслуживания. Полевые данные для этого закрывать не нужно: рейсы правят на вкладке [Рейсы](./Рабочий%20цикл/Рейсы.md).
- Если карточку одновременно сохранил другой пользователь, баннер **Принять обновление / Оставить мои изменения** — это конфликт правок, а не обновление программы. Подробнее в [FAQ](./FAQ.md).
