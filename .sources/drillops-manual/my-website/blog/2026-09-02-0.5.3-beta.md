**Патч Desktop: принудительное обновление данных, серийник сборки из материала, сортировка списков.**

{/* truncate */}

> ✅ Contract v5 — обновление API не требуется.  
> Совместимо с API 0.5.2-beta

---

## Новое

### Обновление данных
- В шапке кнопка **Обновить данные** и хоткей **F5** заново загружают кэш с сервера
- Открытые карточки в режиме просмотра перечитываются; в режиме редактирования черновики не сбрасываются — обновляются только списки ComboBox и AutoCompleteBox

### Сводка
- В колонках показывается серийный номер материала сборки

---

## Исправления

### Отправки и обслуживание
- Незавершённые записи сверху, затем по дате (новые выше)

### Даты
- Набранная в календаре дата сохраняется по кнопке Сохранить, даже если поле не теряло фокус
