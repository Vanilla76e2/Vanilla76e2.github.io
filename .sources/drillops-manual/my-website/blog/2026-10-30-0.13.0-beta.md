# DrillOps 0.13.0-beta

**Минор Desktop + API: веб-клиент только для чтения, состав и сводка с сервера.**

> ⚠️ **Обновляйте Desktop и API вместе** до `0.13.0-beta`.  
> **Contract v13** — старые клиенты и сервер несовместимы.

---

## Новое

### Веб-клиент (Web)
- Просмотр готового оборудования и оборудования на обслуживании, со структурой выбранной сборки
- Список обслуживания, карточка заказ-наряда, полевые данные и сводка. Записи не создаются и не меняются
- Вход теми же учётными записями, что в Desktop

### Состав и сводка (API, Desktop)
- Состав сборки на выбранную дату и сводка оборудования считаются на сервере по журналу операций
- Сохранённый снимок состава в заказ-наряде больше не хранится и не отдаётся клиенту

### Заказ-наряд (Desktop)
- В карточке виден комментарий обслуживания. В режиме правки его можно изменить

---

## Исправления

### Полевые данные (Desktop)
- «Последние полевые данные» и листание вперёд/назад идут по тем же рейсам, что сводка этого инструмента
- Тот же рейс из чужого документа не дублируется, если он уже есть в собственном документе
- Открытие из сводки оставляет в шапке инструмент, из чьей сводки пришли

### Заказ-наряд (API, Desktop)
- Вложения завершённого заказ-наряда нельзя добавлять и удалять

### Глобальный поиск (Desktop)
- Больше не отображает результаты пока не в фокусе

### Списки (Desktop)
- Выбранный элемент больше не появляется поверх других при пролистывании
