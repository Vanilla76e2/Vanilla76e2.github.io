# DrillOps Desktop 0.15.0-beta

**Ожидание ремонта и обслуживания, возврат инструмента в открытой отгрузке, поиск и фильтр типов.**

> ⚠️ Обновляйте **Desktop и API вместе** до `0.15.0-beta`.  
> **Contract v15** — вход на старый сервер будет заблокирован.

---

## Новое

### Операции
- Статус и операция «Ожидает ремонт»
- Операция «Ожидает обслуживания»

### Главная
- В фильтре типов колонки есть «Выбрать всё» и «Сбросить фильтр»

### Заказ-наряд
- Заголовок карточки можно выделить и скопировать

### Глобальный поиск
- При наведении на результат поиска появляется подсказка с комментарием, если он есть
- Для результатов поиска добавлено контекстное меню

---

## Исправления

### Полевые данные и сводка
- Вернувшийся инструмент попадает в полевые данные и сводку, пока отгрузка открыта из-за остальных инструментов
- Рейс после даты возврата этого инструмента к нему не относится
