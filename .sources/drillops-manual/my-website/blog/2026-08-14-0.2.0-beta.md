---

## 🚀 Главное в релизе

### Автообновление Desktop
- Клиент при входе проверяет центральный каталог релизов и предлагает обновление
- Проверка **contract version** — несовместимый setup не предложат
- Установка с выбором: **только текущий пользователь** или **все пользователи** ПК

### Сводка (Summary)
- Новая вкладка **Сводка** — единая лента документов и событий по датам
- Группировка по типам: наряды, отправки, ТО, история полей и др.
- Поиск, фильтры, разворот групп
- **Экспорт в Excel** с детализацией по строкам

### Документация
- Полноценный **файловый менеджер** документов (Desktop + Web Admin)
- Папки, загрузка, скачивание, переименование, удаление
- **Глобальный поиск** по имени файла по всем папкам
- Замена файла при загрузке с подтверждением
- Права доступа через RBAC (`Documentation`: None / Read / Write)

### Аналитика
- Новая вкладка **Аналитика** — метрики по парку оборудования
- Сводка по статусам (готов / в поле / на ТО)
- Матрица статус × шаблон сборки, динамика за период

## 🖥 Desktop — рабочий процесс

### Главная и сборки
- Переработан **Main Workflow** — колонки, статусы, навигация
- **Рекурсивный расчёт комплектности** сборок (вложенные сборки учитываются корректно)
- Фильтры по **шаблонам сборок** вместо типов материалов
- Богаче контекстные меню: открыть сборку, компонент, тип, документы
- «Где установлен» материал в дереве сборок

### Наряды (Work Orders)
- Улучшенный мастер **операций** — prefill, извлечение/вставка материалов
- **Multi-acting** — несколько исполнителей на одной операции
- Навигация prev/next по документам прямо из наряда
- Фильтр по серийному номеру

### Отправки
- Клиент / кластер / месторождение в карточке отправки
- Улучшенная навигация и связи с другими разделами

### История полей (Field History)
- **Версии отчётов** — снимки, diff между версиями
- Улучшенные формы отчётов и матрицы
- Навигация между документами, фильтры

### ТО (Maintenance)
- Фильтры и **бейджи инцидентов**
- Возврат сборки в ТО с привязкой к локации «Цех»
- Уникальные частичные номера

### Текстовые шаблоны
- Шаблоны перенесены **на сервер** (единый источник для всех клиентов)
- Импорт/экспорт, редактирование в Desktop

### Прочее UX
- **История вкладок** TabShell — назад / вперёд как в браузере
- Сброс пароля пользователя (диалог)
- Мелкий polish: локализация, выравнивание колонок, контекстные меню

## 🐛 Исправления и техническое

- Корректный расчёт комплектности вложенных сборок
- Синхронизация `HasTrouble` у материалов
- Убран устаревший статус `Stored`
- Исправления extract/insert в операциях
- Стабильность кэша и SignalR-обновлений
- Множество UX-фиксов по shipments, WO, FH, materials

---

## 🔜 Известные ограничения (beta)

- HTTPS для API — через reverse proxy (Nginx / Traefik)
- AI integration — только read, без записи
- Автообновление касается только Desktop — API обновляется отдельно (Docker)
- При смене contract version сначала обновите API, затем Desktop
