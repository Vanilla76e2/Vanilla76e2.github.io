# DrillOps Desktop 0.14.0-beta

**Момент и нагрузка на долото, уровень L3 и формулы лимитов вибраций.**

> ⚠️ Обновляйте **Desktop и API вместе** до `0.14.0-beta`.  
> **Contract v14** — вход на старый сервер будет заблокирован.

---

## Новое

### Полевые данные
- В подземном рейсе можно записать момент на долоте (kNm) и нагрузку на долото (kN)
- В матрице вибраций есть уровень L3. Он же виден в сводке и в выгрузке Excel

### Лимиты вибраций
- Порог задаётся формулой по часам уровней L3–L7, например `L3 + L4 > 30`
- Если условие выполняется, эти уровни подсвечиваются в полевых данных
- Сохранённый порог одного уровня становится формулой этого уровня
