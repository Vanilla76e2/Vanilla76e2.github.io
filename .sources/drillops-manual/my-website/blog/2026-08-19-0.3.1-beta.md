## 🚀 Что нового
Компоненты — установлено в сборке
• Кнопка «Открыть сборку» объединена с текстом сборки: на кнопке — название сборки, по ширине текста
• Головной материал сборки тоже считается установленным — сборку можно открыть сразу из карточки компонента

Шаблоны — добавление слотов
• При добавлении слотов подряд не сбрасывается выбранный тип и не сворачивается группа в дереве

Комплектность сборок
• Пустые слоты под вложенный шаблон учитываются как нескомплектованные слоты этого шаблона (рекурсивно)

Наряды и отклонения
• Предупреждение об отклонении учитывает вложенные сборки и поднимается к родительским
• В интерфейсе понятнее видно, что в последнем заказ-наряде есть отклонение

Материалы — перемещение
• Действие «Переместить» с выбором цели (вариант / тип / вид)

Вход — обязательное обновление
• Если сервер новее клиента, предлагается скачать и установить обновление (или открыть страницу релизов)

Полевые данные — импорт рейсов
• Импорт только из сохранённых рейсов; уточнены сообщения, если импортировать нечего

Прочее
• Мелкий polish: Main, отправки, мастер операций, nullable-поля в формах
