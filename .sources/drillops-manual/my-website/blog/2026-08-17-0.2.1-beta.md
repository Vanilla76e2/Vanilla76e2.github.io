**Hot Fix:** иконка, сборки и отклик на изменения материалов, блокировка автообновления.

{/* truncate */}

>✅ Contract v2 — обновление API не требуется.
Совместимо с API 0.2.0-beta и новее.

## 🚀 Что нового

Иконка приложения
• Обновлена иконка DrillOps Desktop

Сборки — подписи вариантов компонентов
• При выборе материала в пустой слот сборки отображаются наименования вариантов компонентов
• Проще понять, какой компонент устанавливаете, без открытия карточки материала

Сборки — мгновенная реакция на материалы
• Раздел «Сборки» сразу обновляется при изменении материалов (статус, перемещение, правки)
• Не нужно вручную перезагружать страницу или переключать вкладку

Автообновление — блокировка
• Проверка SHA больше не не блокирует запуск установщика
