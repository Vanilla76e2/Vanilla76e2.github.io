**Патч: сводка по компоненту, операции по выбранному узлу, даты без сдвига дня.**

{/* truncate */}

> ⚠️ Обновляйте **Desktop и API вместе** до `0.4.0-beta`.
> **Contract v4** — вход на старый сервер будет заблокирован. Сначала обновите API.
## Что нового
### Сводка
- Для компонента (и вложенной сборки без своих нарядов) строится линия жизни в сборке-носителе: установка, извлечение, утилизация
- Отправки и полевые данные — только пока компонент был в этой сборке; у извлечённого нет «Готово» на этом ЗН
- Установка не тянет отправку/ПД того же наряда (прошлый рейс); берутся со следующего цикла
- Утилизация: «Утилизировано» вместо «Готово»
- Если компонент не извлекали — «Готово» на завершённом наряде как раньше
- Сводку компонента можно открыть со страниц материалов, сборок и наряда
### Мастер операций
- Выбор компонента для Repair, Maintenance, Waiting for parts (корень сборки тоже в списке)
- Extract / Scrap — по-прежнему только прямые компоненты слотов
### Даты
- Дата операции — календарный день, без сдвига на −1 в часовых поясах вроде UTC+5
### Аналитика
- Ожидание ЗИП: от Waiting for parts до следующего Maintenance того же компонента
### Отмена операций
- После отмены обновляется кэш нарядов (в т.ч. пустой дочерний ЗН после извлечения на ТО)
