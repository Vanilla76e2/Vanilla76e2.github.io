# DrillOps 0.12.2-beta

**Патч Desktop: наработка в составе, сводка рейсов и структура старых заказ-нарядов.**

> ✅ Contract v12 — обновление API не требуется.  
> Совместимо с API 0.12.1-beta

---

## Новое

### Состав сборки (Desktop)
- В дереве сборки, на главной, в заказ-наряде и в снимке состава отгрузки у компонента видна наработка в часах
- В закрытом заказ-наряде и на снимке отгрузки часы — на дату документа
- Снимок, сохранённый без наработки, дополняется по серийному номеру

---

## Исправления

### Заказ-наряд (Desktop)
- В закрытом заказ-наряде состав берётся из операций закрытых нарядов, в том числе задним числом, а не из текущего состава
- Установка и извлечение в наряде на компонент учитывают такие операции закрытого наряда на сборку
- Списание в закрытом наряде учитывается на эту дату: списанный компонент не предлагается к установке позже

### Обслуживание (Desktop)
- Запись задним числом можно создать на сборку, которая стоит внутри другой сборки
- В поле выбора достаточно серийного номера, если он один в списке

### Сводка (Desktop)
- Рейс показывается один раз, вместе с обслуживанием после подъёма. Следующее обслуживание открывает новый период
- Полевые данные остаются на отгрузке, которая закрыла рейс, даже если документ оформлен после извлечения компонента
- Рейс и его часы видны у каждого инструмента из компоновки
- Обслуживания, у которых заказ-наряды начинаются в разные дни, не склеиваются в один период
- Обслуживание после подъёма остаётся со своей отгрузкой, если внутри рейса есть более раннее «готово»
- Повтор того же рейса другим номером документа не дублируется
- Период отгрузки показан отдельной строкой

### Отгрузки (Desktop)
- Блок инструментов называется «Инструменты»
