## Кратко
Первый публичный alpha-релиз DrillOps: учёт бурового оборудования с настольным клиентом для операторов, сервером API + Web Admin и PostgreSQL.

Готовый Docker-образ API опубликован на Docker Hub: `vanilla76e2/drillops-api:0.1.0-alpha`

## Развёртывание
Docker Hub: `vanilla76e2/drillops-api:0.1.0-alpha`
Desktop: `DrillOps.Desktop-Setup-0.1.0-alpha.exe / MSI (Windows x64)`
API (Windows): `DrillOps.API-Setup-0.1.0-alpha.exe / MSI`
Документация: `README в репозитории, каталог packaging/`

## DrillOps.Desktop (операторы)
- Главный экран: колонки «Готово / В поле / Техобслуживание», фильтры, контекстные действия
- Компоненты: справочник Вид → Тип → Вариант → Компонент, наработка, свойства (матрица L4–L7)
- Сборки: шаблоны и сборки, дерево компонентов, слоты, назначение и извлечение материалов
- Отправки, клиенты, локации
- Техобслуживание и наряды (Work Order) с операциями
- Полевая история: отчёты по рейсам, матрицы вибраций, вложения
- Вкладки с откреплением, локализация RU/EN
- Вход: сохранение URL API, проверка совместимости версии клиента и API

## DrillOps.API + Web Admin
- REST API, SignalR, JWT-аутентификация
- RBAC: роли и матрица прав по модулям
- Web Admin (isSA): пользователи, роли, мониторинг
- Версионирование API и проверка совместимости с Desktop
- Хранение вложений на диске
- Миграции БД при старте

## Инфраструктура и упаковка
- Docker Compose: API + PostgreSQL; вариант с внешней БД
- Скрипты сборки: packaging/Build-All.cmd, Inno Setup, WiX MSI
- Примеры compose для production

## Требования
- Сервер (Docker): Docker, Docker Compose, PostgreSQL 14+ (в compose или внешняя)
- Сервер (Windows): Windows Server / Win 10+, PostgreSQL 14+
- Desktop: Windows 10/11 x64
- Браузер (Admin): современный Chromium / Edge / Firefox

## Известные ограничения alpha
- Версии Desktop и API должны совпадать по контракту (0.1.0-alpha)
- Production: обязательно сменить Jwt__Key и пароли БД; рекомендуется HTTPS
- Возможны ошибки UI и неполное покрытие сценариев — приветствуется обратная связь от тестировщиков

## Установка (быстрый старт)

```bash
docker pull vanilla76e2/drillops-api:0.1.0-alpha
```

Отредактируйте `docker-compose.yml` (образ `vanilla76e2/drillops-api:0.1.0-alpha`, секреты JWT и БД). Примеры: `packaging/docker/`

```bash
docker compose up -d
```

**Desktop:** URL `http://<сервер>:8080/`, вход под учётной записью из Web Admin.
