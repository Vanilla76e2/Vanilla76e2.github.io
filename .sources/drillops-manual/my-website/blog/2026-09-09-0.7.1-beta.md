**Хотфикс Desktop: сводка и наработка, привязка ПД к рейсу, фильтр заготовок.**

{/* truncate */}

> ✅ Contract v7 — обновление API не требуется.
> Совместимо с API 0.7.0-beta

## Новое

### Сводка
- У рейса отдельная строка с деталями

### Обслуживание
- В строке полевых данных видны дата и часы наработки

### Заготовки
- Список можно отфильтровать по типу; экспорт сохраняет все заготовки, не только видимые

## Исправления

### Сводка
- Часы периода считаются по отчётам ПД, даже если дата записи не попадает в интервал; одна и та же наработка не дублируется между периодами

### Полевые данные
- Рейс подбирается по датам спуска и подъёма в отчётах, а не по дате карточки ПД
