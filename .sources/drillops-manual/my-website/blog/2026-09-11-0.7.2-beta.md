**Патч Desktop: метры в аналитике, фильтры отправок, сводка и наработка, каскад обслуживания.**

{/* truncate */}

> ✅ Contract v7 — обновление API не требуется.  
> Совместимо с API 0.7.1-beta

---

## Новое

### Аналитика
- Карточка «Метров пробурено» за выбранный период, с разбивкой по типу и серийному номеру

### Отправки
- Список фильтруется по типу оборудования, локации и заказчику

### Полевые данные
- В диалоге импорта отчёта ПД можно найти поиском, а не только выбрать из списка

### Компоненты
- Комментарий виден в списке и участвует в поиске

---

## Исправления

### Сводка
- Рейс и полевые данные прошлого цикла не попадают в более позднее обслуживание другой сборки
- Часы в шапке считаются по той же логике, что периоды на шкале

### Наработка
- Часы из отчётов ПД не садятся на период «готово» без полевых данных

### Обслуживание
- Удаление записи обслуживания уносит связанные заказ-наряд и полевые данные в корзину

### Заказ-наряд и полевые данные
- Кнопки «предыдущий / следующий» пропускают документы без живой записи обслуживания
