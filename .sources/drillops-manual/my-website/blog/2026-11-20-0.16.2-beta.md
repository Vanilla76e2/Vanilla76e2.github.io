# DrillOps Desktop 0.16.2-beta

**Период компонента на сводке, один рейс вместо копий и файлы на вкладку заказ-наряда.**

> ✅ Contract v16 — обновление не блокирует вход.  
> Совместимо с API 0.16.1-beta

---

## Новое

### Заказ-наряд
- Файл можно перетащить на вкладку слота: паспорт, чек-листы и тестирование, калибровка, отклонения, инспекции. Файл попадает в этот слот

---

## Исправления

### Сводка
- После извлечения компонента из инструмента карточка не тянется до конца заказ-наряда этого инструмента. Период — даты операций с компонентом
- Один рейс, записанный сразу на несколько отправок, остаётся один раз: на отправке этой карточки
- Рейс с чужой сборкой на том же документе полевых данных не добавляет часы
- Если заказ-наряд начался и закончился в один день, в подписи одна дата
