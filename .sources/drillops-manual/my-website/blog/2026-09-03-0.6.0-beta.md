## Новое

### Наработка компонента
- Часы закрытых ПД приходят с сервера как рассчитанные рейсовые строки
- Рейсовые строки в карточке материала только для чтения; вручную по-прежнему можно добавить свои часы

### Полевые данные
- «Добавить рейс» доступна при праве записи, без лишних условий по справочникам
- Новый ПД с главной и обслуживания сразу открывается с формой нового рейса

### Интерфейс
- У текстовых полей контекстное меню **Копировать**

---

## Исправления

### Полевые данные
- Первое сохранение закрывает ПД

### Заказ-наряд
- В наработку на начало ЗН входят часы за дату старта, а не только строго до неё

### Обслуживание
- Активные записи без заказ-наряда стоят сверху списка

### Локации
- После сохранения и удаления список и карточка обновляются из кэша, выбор не сбрасывается
