## 🚀 Что нового

Обновление — вкладка вместо баннера
• Если есть новая версия, при каждом входе открывается вкладка «Обновление»
• Патчноут берётся из GitHub Releases и показывается в теме приложения
• Кнопка «Скачать» ставит обновление; «Сайт» открывает страницу релиза

Шапка — руководство
• Кнопка info справа от смены темы открывает руководство пользователя

Шаблоны сборок — правка слотов
• Выбранный в дереве слот можно править (тип и суффикс), не только корень шаблона

Материалы — перемещение
• «Переместить» нельзя, если элемент уже используется: компонент в сборке, у варианта есть установленные SN, на типе есть шаблон или слот
