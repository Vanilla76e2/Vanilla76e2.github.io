# DrillOps Desktop 0.16.0-beta

**Счётчики часов и их сброс, типоразмер и отчёт «Статус оборудования», лимиты показателей рейса, флаг инспекции и новые темы.**

> ⚠️ Обновляйте **Desktop и API вместе** до `0.16.0-beta`.  
> **Contract v16** — вход на старый сервер будет заблокирован.

---

## Новое

### Счётчики часов
- В карточке типа компонента можно завести счётчики часов: наименование и лимит в часах
- Один счётчик можно показывать рядом с общей наработкой: на главной, в сборках и в заказ-наряде. Превышение лимита подсвечивается, остальные счётчики видны в подсказке
- Операция «Сброс счётчиков» в заказ-наряде обнуляет выбранные счётчики компонента

### Тип компонента
- Поле «Типоразмер»
- Лимиты рейса: формулы для песка, твёрдой фазы, pH, хлоридов, температуры, DSL, давления, момента и нагрузки на долото. X — значение показателя на рейсе

### Полевые данные
- Показатель рейса, превысивший лимит, подсвечивается, в подсказке — сработавшая формула
- Матрицы вибраций по умолчанию показывают сумму по всем рейсам. «Раздельное отображение» показывает выбранный рейс

### Аналитика
- Отчёт «Статус оборудования»: поиск, фильтры по статусу, типоразмеру, оборудованию и месторождению, экспорт в Excel

### Главная
- В колонке «На обслуживании» видно, была ли инспекция в последнем заказ-наряде
- Сборки в колонках идут группами по шаблону. В группе отгрузки «В поле» тоже

### Настройки
- Раздел «Интерфейс»: флаг инспекции на главной и скрытые типы сборок
- Темы Topaz, Nordic, Typewriter, Gruvbox и Coffee, у каждой светлый и тёмный вариант
- Локация цеха называется «СЦ»

---

## Исправления

### Обслуживание
- Повторная отправка в обслуживание не создаёт вторую запись, если последняя ещё не закрыта
- Полевые данные и сводка относят рейс к записи обслуживания с заказ-нарядом, а не к брошенной записи без него

### Отгрузки
- Инструмент, убранный из состава открытой отгрузки, удаляется из неё и становится готовым, а не числится вернувшимся
- Для сборки показывается её открытая отгрузка, даже если есть более новая плановая или завершённая
